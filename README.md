# 💡 What is ShopPilot AI?

ShopPilot AI is a browser-based AI-powered retail automation platform designed specifically for Indian kirana stores and local businesses.

The system combines:

- 🎙️ Voice-based billing
- 📦 Smart inventory automation
- 📊 Real-time analytics
- 💳 Udhaar / Khata management
- 🧾 AI invoice generation
- 🤖 Autonomous wholesale negotiation agents
- 🔊 Hindi & English voice confirmations

into one intelligent retail ecosystem.
